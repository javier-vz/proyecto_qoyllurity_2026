# Qoyllur Rit’i · Corpus bibliográfico y grafo mínimo 2026

**Fecha:** 2026-11-08  
**Entrega:** Biblioteca verificada de fuentes y proyección RDF espacial/documental mínima. **No se ha modificado GitHub ni el TTL de 2025.**

## Contenido

- `01_bibliografia/`: catálogo de **35 referencias externas verificadas**, con autores, fecha, URL original, DOI cuando existe, evaluación de derechos, prioridad y fichas de lectura originales.
- `02_grafo_minimo/`: TTL de 2026, doce tramos, relaciones y evidencia de cada enlace, además de decisiones aplazadas.
- `03_informes/`: revisión temática y guía de evaluación del corpus/IA.
- `04_documentos_ligados/`: **35 accesos directos `.url`** que llevan a los documentos de las fuentes editoriales/institucionales; no contienen copias no autorizadas de los textos.
- `05_manuscrito_aportado/`: material original previamente entregado en esta conversación, sólo para revisión interna (si se incluye al crear el archivo completo).

## Alcance y limitación de descarga

Se intentó recuperar PDFs directamente desde las revistas y repositorios consultados, pero el entorno no permitió descargar los archivos binarios de fuentes externas. En consecuencia, **el ZIP no contiene los PDFs completos de esas fuentes**. Sí contiene enlaces públicos verificables, documentación bibliográfica y notas de lectura originales para cada fuente. No se debe interpretar un enlace disponible como permiso para redistribución o entrenamiento de IA.

Se incluye el manuscrito aportado por el usuario solo en la versión completa si se empaqueta; tiene condición de **texto en evaluación**, no es fuente pública ni material de entrenamiento autorizado.

## Acceso rápido

1. Abrir `Bibliografia_y_Grafo_Qoyllur_Riti_2026.xlsx` (incluido en la carpeta raíz del ZIP).
2. Filtrar la columna `Uso_IA` / `Permiso_entrenamiento` en la hoja de derechos.
3. Abrir las fichas `*_ficha.md` para obtener contexto y enlaces.
4. Abrir `02_grafo_minimo/README.md` para entender vocabulario, límites probatorios y consultas SPARQL.

## Reglas para futuros documentos y modelos

No mezclar 2025 y 2026 sin provenance; no asumir que un waypoint define oficialmente un lugar; no atribuir todos los tramos GPS a una Nación; no entrenar indiscriminadamente con material NC-ND o de licencia incierta; no publicar puntos personales o sensibles sin revisión comunitaria.
